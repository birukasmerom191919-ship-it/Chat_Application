# 💬 Chat Application

A modern frontend chat application built with React. It provides a clean messaging interface with multiple conversations, emoji support, user profiles, and message persistence.

## 🚀 Features

- Chat interface with multiple users
- Send and receive messages
- Automatic chat replies
- Search conversations
- Emoji picker support
- Messages saved with Local Storage
- Auto-scroll to latest messages
- User profile information
- Responsive dark theme UI

## 🛠️ Technologies Used

- React.js
- CSS Modules
- React Icons
- Emoji Picker React
- Framer Motion
- Local Storage

## ⚙️ Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project folder:

```bash
cd chat_application
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm start
```

Open in your browser:

```
http://localhost:3000
```

## 📌 How to Use

- Select a chat from the sidebar
- Search for conversations
- Type and send messages
- Use emojis from the emoji picker
- Messages remain saved after refreshing the page
